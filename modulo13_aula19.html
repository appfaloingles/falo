Fun vs Funny (e Hard vs Hardly, Most vs Almost)

Três armadilhas num golpe só! Fun = divertido, dá prazer; funny = engraçado, dá risada. Hard = difícil/duro; hardly = quase não (não é 'de forma dura'!). Most = a maioria; almost = quase. Toque pra ouvir.

😄 fun / funny😆 hard / hardly📊 most / almost🗣️ Fala
AFun x Funny

Fun or funny? — divertido x engraçado

Toque pra ouvir. Fun te dá prazer; funny te dá risada.

🎯

A ideia: fun = a coisa é divertida, você curte (the party was fun). funny = a coisa é engraçada, faz rir (the joke was funny). Uma festa é fun; uma piada é funny. Cuidado: 'funny' também pode significar 'estranho'.

BHard x Hardly

Hard or hardly? — difícil x quase não

Toque pra ouvir. Hardly NÃO é 'de forma dura' — é 'quase não'.

⚠️

Pegadinha: hard = difícil ou duro (a hard test, work hard). hardly = quase nada, quase não (I can hardly hear you = quase não te escuto). E most = a maioria (most people); almost = quase (almost done). Não troque 'most' por 'almost'!
