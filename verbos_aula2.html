There is / There are — "tem" em inglês

Em inglês, o "tem" de existência NÃO é "have" — é there is (singular) e there are (plural). Toque pra ouvir.

📦 Existência1️⃣ there is🔢 there are❓ some / any
👋A grande sacada

"Tem" não é "have"

No português, "tem um problema" usa ter. No inglês, existência é there is / there are — nunca "have".

💡

"There is a problem" = tem um problema. "There are two cafés" = tem dois cafés. Singular → there is, plural → there are.

Athere is / there are

Um ou vários?

there is pra um, there are pra vários. Toque em cada um pra ouvir.

🎯

Regra: uma coisa → there is (there's). Duas ou mais → there are.

BNegar e perguntar

There isn't / Is there…?

Pra negar, põe not. Pra perguntar, inverte. Toque pra ouvir.

🗣️

Use some em frases afirmativas e any em negativas e perguntas: "Is there any milk?"

CFrases de verdade

There is/are no dia a dia

Frases prontas que você vai usar de verdade. Toque pra ouvir e repita.

DNegar e perguntar

Não tem / Tem…?

Mais frases com there isn't/aren't e perguntas. Toque pra ouvir.

⚠️

Nunca use "have" pra existência: é "There is a problem", não "There has a problem".
