Each / Every / All — cada e todos

Três palavras que se confundem: each (cada, um por um), every (todo/cada, o grupo inteiro) e all (todos, junto). O pulo do gato: each e every pedem o verbo no singular, all pede plural. Toque pra ouvir.

1️⃣ each (um por um)🔁 every (todo)👥 all (todos)🗣️ Fala
AVocabulário

Each or every? — cada um ou cada

Toque pra ouvir. Repare: os dois pedem SINGULAR depois.

🎯

A regra: each foca em um por um (each student got a book). every vê o grupo todo (every student passed). Os dois usam o substantivo no singular: each day, every day.

BO grupo inteiro

All — todos juntos

Toque pra ouvir. All junta tudo e pede PLURAL.

⚠️

Cuidado com o verbo: each/every pedem singular (Every day is different), mas all pede plural (All the days are busy). Muita gente do BR erra isso!
