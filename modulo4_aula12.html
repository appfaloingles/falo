Used to / be used to / get used to — a pegadinha clássica

Três formas parecidas, três sentidos bem diferentes. Used to = hábito antigo; be used to = já estar acostumado; get used to = se acostumando aos poucos. Confundir é o erro nº1 do brasileiro. Toque pra ouvir.
